# Yohan — Personal Portfolio

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript. The design uses a dark navy/charcoal base with electric-blue accents, a real-photo slot, and restrained motion. It intentionally avoids generated character artwork and decorative line motifs.

## Preview locally
1. Extract the project ZIP.
2. Open `index.html` in a browser.
3. To display your own portrait, add a photo named `profile.jpg` inside the `assets` folder. A portrait-oriented image works best.

## Personalize before publishing
1. In `index.html`, replace every `YOUR_GITHUB_USERNAME` with your exact GitHub username.
2. Add `assets/profile.jpg` with the photo you want to use. The site currently shows a simple monogram placeholder until that file exists.
3. Review the project cards. Keep only projects you are comfortable presenting, and update their descriptions/status as your work changes.
4. Update the About section if you want to change how you introduce yourself.

## Publish with GitHub Pages
1. Create a **public** repository named exactly `YOUR_GITHUB_USERNAME.github.io` (replace the placeholder with your actual username).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder to the repository root.
3. Open **Settings → Pages** in that repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. GitHub Pages will publish the site at `https://YOUR_GITHUB_USERNAME.github.io`.

## Notes
- The site uses plain HTML, CSS, and JavaScript, with no build step or framework required.
- The layout is responsive and includes a reduced-motion accessibility preference.
- The project descriptions distinguish coursework, concepts, and work in progress rather than presenting them as completed professional products.
